# DwanZhang / AI Notes

A bilingual personal blog hosted on GitHub Pages with Jekyll. The homepage opens in English. The language link opens the corresponding Chinese page.

The first post is [40 Ways to Build a Bad Verifier](https://dwanzhang-ai.github.io/posts/40-ways-to-build-a-bad-verifier/). Its English and Chinese text lives in `_data/verifier.json`, and `_includes/verifier-article.html` renders both versions. Jekyll generates the article feed at `/feed.xml` from `_posts/`.
