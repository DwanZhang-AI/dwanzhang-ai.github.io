# DwanZhang / AI Notes

A bilingual personal blog hosted on GitHub Pages with Jekyll. The English homepage at `/` and the Chinese homepage at `/zh/` list articles from `_posts/` in reverse chronological order. The language link opens the corresponding homepage or article.

The first post is [40 Ways to Build a Bad Verifier](https://dwanzhang-ai.github.io/posts/40-ways-to-build-a-bad-verifier/). Its English and Chinese text lives in `_data/verifier.json`, and `_includes/verifier-article.html` renders both versions. Its post front matter supplies the listing excerpts, Chinese permalink, and cover image. Jekyll generates the article feed at `/feed.xml` from `_posts/`.
